# economy-of-informatization-exam
# Экономика информатизации — Решения экзаменационных задач
## О репозитории
Данный репозиторий содержит решения экзаменационных задач по курсу
"Экономика информатизации". Все решения выполнены в формате Jupyter Notebook
с визуализациями и экономической интерпретацией результатов.
## Структура репозитория
- `notebooks/` — Jupyter Notebook с решениями задач
- `data/` — исходные данные для задач
- `reports/` — экспортированные отчеты (PDF/HTML)
- `utils/` — вспомогательные функции
